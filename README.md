# COCR — Start Right

A tiny 5KB student starter inspired by COCR.

Pick a goal — Learn, Build, or Explore — and get a 3-step quest with a clear first move.

Progress is saved locally on the device. No account, backend, external libraries, images, or tracking.

## Run

Open `index.html` directly in any modern browser.

## Size

`index.html`: 4,998 bytes

Measured as the raw file size in bytes, before compression.

## Built for

The Crescent "Cards – The Lightweight" challenge.

The whole experience is intentionally kept in one HTML file with inline CSS and JavaScript.
